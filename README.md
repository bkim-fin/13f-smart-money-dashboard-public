# Smart Money Signal Dashboard

Public-safe static dashboard for reviewing anonymized institutional positioning signals, sector rotation, seven-day price trends, and portfolio risk guidance.

## Live Site

The dashboard is published through GitHub Pages from this repository.

## Public Data Only

This repository intentionally excludes manager identities, private research notes, source mappings, and local-only dashboards. The published signals are delayed, anonymized, and intended for medium-term research rather than real-time trading.

## Updates

- `dashboard_public_data.json`: anonymized signal and allocation data
- `prices.json`: seven-day market data
- `update_prices.py`: price refresh script

Price data is refreshed automatically on U.S. trading weekdays.

## Disclaimer

This dashboard is for research and educational purposes only. It is not personalized investment advice.
